El motor

¿Qué es un LLM?

Primera parte: entender el motor = el modelo de lenguaje (LLM).
LLM · Large Language Model

Un autocompletar gigante

"El carnaval de Pasto es de Negros y  ? "
Blancos
94%
Rojos
3%
Cuyes
2%
Azules
1%

📚 Leyó casi todo internet → aprendió patrones del lenguaje

Pregunta al público: ¿qué palabra sigue? → todos dicen "Blancos". Eso hace un LLM: calcula probabilidades de la siguiente palabra (token), una y otra vez. Haz CLIC en las barras para completar la frase (la de "Cuyes" da risa). Entrenado con muchísimo texto → aprendió gramática, datos, razonamiento aparente.

Un motor potente… pero quieto

No sabe qué hora es
No ve el clima de hoy
No puede actuar
El LLM es como un MOTOR: muchísima potencia, pero un motor solo encima de una mesa no te lleva a ningún lado. Limitaciones: su conocimiento se congela en la fecha de entrenamiento, no sabe la hora, no consulta el clima, no puede enviar un correo ni guardar un archivo. Solo genera texto. Pregunta: ¿qué le falta para moverse? → un carro.
02

El auto

¿Qué es un agente de IA?

Segunda parte: de motor a auto = de LLM a agente.

Agente = motor + auto

La metáfora central. Ve mostrando pieza por pieza (flecha derecha): 1) MOTOR = el LLM. Da la "inteligencia" / potencia. 2) VOLANTE = las instrucciones (system prompt): hacia dónde y cómo se comporta. "Eres un guía pastuso amable". 3) BAÚL = la memoria: lo que hablamos antes, documentos, contexto. 4) RUEDAS = las herramientas: funciones que el agente PUEDE USAR para tocar el mundo: consultar clima, buscar en una base de datos, enviar un correo, generar una imagen. Frase clave: "Un agente es un LLM que puede DECIDIR qué herramientas usar para cumplir un objetivo".

Mismo motor, distintos autos

🏎️Carreras⚙️ mismo motor

💻Código🧠 mismo LLM

🎵Música🧠 mismo LLM

Con el MISMO motor puedes armar un camión de carga, uno de carreras, una ambulancia o un tractor. Lo que cambia es la carrocería, las ruedas, el volante: para qué está hecho. Igual en IA: con el mismo LLM se arman agentes de código, de video, de imágenes, de música… Y lo más bonito: podemos armar el NUESTRO, personalizado → eso es lo que vamos a hacer hoy.

¿Cómo maneja un agente?

👤 ¿Qué ropa llevo hoy en Pasto?
🧠 Necesito saber el clima…
🔧 clima_actual("pasto")
👀 12 °C · 70% de lluvia
✅ ¡Achichay! Saco y paraguas ☔
El ciclo del agente (agent loop): PENSAR → ACTUAR (usar una herramienta) → OBSERVAR el resultado → repetir si hace falta → RESPONDER. Recorre el ejemplo paso a paso. Lo importante: NO programamos el "if clima…". El LLM DECIDE solo qué herramienta usar. Eso es lo que lo diferencia de un chatbot normal.

Amazon Bedrock: servicio administrado donde eliges el motor (modelo) que quieres sin montar servidores ni GPUs. Cambias de motor cambiando un parámetro (model_id). Pagas por tokens usados. Hoy usamos Amazon Nova: rápido y barato, ideal para demos con mucha gente.

pip install strands-agents

Strands Agents: SDK de código abierto que publicó AWS (nació en equipos internos de AWS, p. ej. Amazon Q Developer). Filosofía "model-driven": tú das las piezas y el modelo decide cómo manejar. Sin flujos rígidos. Solo 3 ingredientes: modelo + herramientas + prompt. Funciona con Bedrock y con otros proveedores.

Tu primer agente en ~20 líneas


from strands import Agent, tool
from strands.models import BedrockModel
from herramientas import calcular, hora_actual

# 🧠 1) EL MOTOR: un LLM en Amazon Bedrock
motor = BedrockModel(
    model_id="us.amazon.nova-lite-v1:0",
    region_name="us-west-2",
)

# 🔧 2) UNA RUEDA: cualquier función de Python
@tool
def contar_letras(palabra: str, letra: str) -> int:
    """Cuenta cuántas veces aparece una letra en una palabra."""
    return palabra.lower().count(letra.lower())

# 🚗 3) EL AUTO: motor + volante + ruedas
agente = Agent(
    model=motor,
    system_prompt="Eres un asistente pastuso, amable y breve.",
    tools=[calcular, hora_actual, contar_letras],
)

agente("¿Qué hora es? ¿Cuántas 'a' tiene 'Ananay'?")
Avanza con la flecha y se resalta cada parte: 1) Importamos Strands. 2) MOTOR: BedrockModel con Nova Lite. 3) RUEDA propia: el decorador @tool convierte una función en herramienta; el docstring le explica al LLM para qué sirve. 4) AUTO: Agent junta motor + prompt + herramientas (calcular y hora_actual están en demo-1-simple/herramientas.py, también hechas con @tool). 5) ¡Arrancar! Una sola línea. Dato curioso: los LLM son malos contando letras (tokens) → por eso le damos una herramienta.

Contenedor = como un auto que ya viene armado con TODO lo que necesita (Python, librerías, código). Corre igual en mi PC y en la nube. ECR = donde guardamos esa imagen. Fargate = AWS pone la carretera: ejecuta el contenedor sin que yo administre servidores. Y toda la infraestructura está escrita como código (CDK): un comando y se crea todo; otro comando y se destruye.

La arquitectura de Galeritas 🌋

Recorre de izquierda a derecha: sus celulares entran por CloudFront (HTTPS) → Load Balancer → contenedor en Fargate. Dentro está el agente Strands: el motor es Nova en Bedrock; tiene 3 ruedas: clima real (API Open-Meteo), base de conocimiento de Pasto, y generación de imágenes con Stable Image Core (Stability AI, también dentro de Bedrock: ¡otro motor del concesionario!). Todo lo que pasa se transmite en vivo al muro (pantalla grande).
